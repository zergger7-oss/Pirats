# Pirates IO MVP — запуск с телефона

Это первый сетевой прототип, а не готовая MMO. В нём уже предусмотрены:
- простая 3D-сцена от третьего лица;
- мобильный джойстик;
- общий сервер через Socket.IO;
- видимые другие игроки;
- общие ракушки и крабы, которые нельзя собрать дважды;
- серверный кошелёк с монетами;
- Telegram Mini App пока НЕ подключён — сначала проверяем игровое ядро.

## Важные требования
Нужен Node.js 18+ на хостинге. Запускать сервер только внутри Acode на телефоне не обязательно: Acode — редактор, а сетевой сервер должен работать в интернете постоянно.

## Самый простой путь с Android
1. Скачай ZIP и распакуй его в Acode или файловом менеджере.
2. Создай новый Node.js-проект на выбранном хостинге, который поддерживает постоянный Node.js-процесс и WebSocket.
3. Загрузи `package.json`, `server.js` и папку `public`.
4. Запусти команду `npm install`, затем `npm start` (обычно хостинг делает это сам по `package.json`).
5. Открой выданный HTTPS-адрес на телефоне. В `/health` должен появиться JSON с `ok: true`.
6. Открой этот адрес во втором браузере или на другом телефоне. Персонажи должны видеть друг друга.
7. Проверь: двигайся джойстиком, подойди к ракушке/крабу и нажми «Собрать». Монеты должны увеличиться у собравшего игрока, а ресурс исчезнуть у всех.

## Почему пока не Telegram
Сначала проверяем, что сетевое ядро работает в обычном мобильном браузере. Затем добавим Telegram WebApp SDK, вход через Telegram и кнопку запуска у бота. Так проще искать ошибки.

## Известные ограничения прототипа
- Пока один тестовый остров; пять островов и корабли — следующие этапы.
- Нет постоянного сохранения между сессиями.
- Нет защиты от всех видов читов и нет полноценной авторитетной физики.
- Персонажи и ресурсы — примитивные 3D-модели.
- Не добавляй секреты, токены бота или пароли в публичные файлы.
